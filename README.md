## Development

Open `SponsorApp.xcodeproj` in Xcode 27 or later. Swift Package Manager resolves Firebase 12.19.1 and SideMenu 6.5.0. iOS 16 or later is supported. Add the app's `GoogleService-Info.plist` to its target for Firebase functionality; absent configuration shows a setup screen.
